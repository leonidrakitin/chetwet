# Claude Design System Guidelines

## 1. Color Palette (Warm & Editorial)
- **Background Main:** #F4F3EE (Warm Beige / Pampas) - Use this instead of white.
- **Surface/Cards:** #FFFCF5 or #FFFFFF (Soft contrast against beige).
- **Primary Text:** #3F3E3A (Charcoal, never pure black).
- **Secondary Text:** #767470 (Warm Gray).
- **Accent/Brand:** #D97757 (Terracotta/Crail) - Use for primary buttons/highlights.
- **Borders:** Very subtle, e.g., #E6E4DD.

## [...](asc_slot://start-slot-3)2. Typography
- **Headings (H1-H3):** Use a Serif font (e.g., 'Lora', 'Tiempos', 'Merriweather'). Font-weight: Medium/Regular.
- **UI Text / Body:** Use a clean Sans-Serif (e.g., 'Inter', 'Halyard', 'System UI').
- **Rules:** 
  - Generous line-height (1.6).
  - Letter-spacing: slightly tight for headings (-0.02em).

## 3. Shapes & UI
- **Border Radius:** 8px to 12px (Soft, but not fully round).
- **Shadows:** Diffuse and warm, not sharp black.
- **Layout:** Centered "Islands" of content on a beige background.
